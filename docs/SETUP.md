# 설치·설정 안내 (처음 하는 사람 기준)

순서대로 하면 됩니다. 화면 이름은 서비스가 바꿀 수 있어서 조금 다를 수 있어요. 비슷한 이름의 버튼을 찾으면 됩니다.

| 부 | 하는 일 | 걸리는 시간 |
|---|---|---|
| 1부 | 이 코드를 GitHub 저장소에 올리기 | 5분 |
| 2부 | Render 에 변환 서버 만들기 | 10분 |
| 3부 | 구글 드라이브 저장 준비 (건너뛰어도 됨) | 15분 |
| 4부 | APK 받아서 폰에 설치하기 | 15분 (대부분 기다리는 시간) |
| 5부 | 앱 사용하기 | |

---

## 1부. GitHub 에 올리기

Windows PowerShell 을 열고, 이 폴더(`wikidocs-book-to-pdf`)로 이동한 뒤 아래를 한 줄씩 실행합니다.

```powershell
cd C:\경로\wikidocs-book-to-pdf
git remote add origin https://github.com/jeong-jihyun/wikidocs-book-to-pdf.git
git branch -M main
git push -u origin main
```

- `remote origin already exists` 라고 나오면 두 번째 줄은 건너뛰세요.
- 처음 올리면 GitHub 로그인 창이 뜹니다. 로그인하면 됩니다.
- 올리는 순간 `mobile/` 폴더가 들어 있으므로 **GitHub Actions 가 자동으로 APK 만들기를 시작**합니다 (4부에서 확인).

## 2부. Render 에 서버 만들기

1. 브라우저에서 <https://dashboard.render.com> 에 접속해 **GitHub 계정으로 가입/로그인**합니다.
2. 오른쪽 위 **New +** 버튼 → **Blueprint** 를 누릅니다.
3. GitHub 연결을 묻는 화면이 나오면 **Connect GitHub** → 저장소 접근을 허용합니다. (`wikidocs-book-to-pdf` 저장소만 골라도 됩니다.)
4. 저장소 목록에서 **wikidocs-book-to-pdf** 옆의 **Connect** 를 누릅니다.
5. 서비스 이름 `wikidocs-book-to-pdf` 가 보이고 아래에 `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` 입력칸이 있습니다. **지금은 비워 두고** 맨 아래 **Deploy Blueprint**(또는 Apply)를 누릅니다. (3부에서 채웁니다.)
6. 서비스 화면에서 **Events / Logs** 로 빌드가 진행됩니다. 처음엔 5~10분 걸립니다. 맨 위 상태가 **Live** 가 되면 완료입니다.
7. 서비스 화면 왼쪽 위 이름 아래의 주소(`https://wikidocs-book-to-pdf-xxxx.onrender.com` 같은 모양)를 **복사해 메모**해 둡니다. → 앱의 "서버 주소"
8. 왼쪽 메뉴 **Environment** 를 누르고 `API_KEY` 줄의 눈 모양(보기) 버튼을 눌러 값을 **복사해 메모**합니다. → 앱의 "API 키"
9. 주소 뒤에 `/health` 를 붙여 브라우저에서 열어 봅니다. `{"ok":true,...}` 가 보이면 서버 성공입니다.

> **무료 플랜 참고**: 15분쯤 안 쓰면 서버가 잠듭니다. 다음에 쓸 때 깨어나는 데 1분쯤 걸립니다. 서버가 다시 시작되면 진행 중이던 작업과 구글 로그인 상태가 사라져요(다시 하면 됩니다).

## 3부. 구글 드라이브 저장 준비 (선택)

드라이브 저장이 필요 없으면 이 부는 건너뛰세요. PDF 는 폰으로 받을 수 있습니다.

### 3-1. 프로젝트 만들고 드라이브 기능 켜기
1. <https://console.cloud.google.com> 에 구글 계정으로 접속합니다. (약관 동의 화면이 나오면 동의)
2. 맨 위 프로젝트 선택 칸 → **새 프로젝트** → 이름 `wikidocs-pdf` → **만들기**. 만들어지면 그 프로젝트를 선택합니다.
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** 로 갑니다.
4. 검색칸에 `Google Drive API` 를 입력해 선택하고 **사용** 버튼을 누릅니다.

### 3-2. 로그인 화면(동의 화면) 설정
1. 왼쪽 메뉴 **API 및 서비스 → OAuth 동의 화면** (또는 **Google Auth Platform**) 으로 갑니다. **시작하기** 를 누릅니다.
2. 앱 이름 `위키독스 PDF`, 사용자 지원 이메일은 내 이메일을 고릅니다.
3. 대상(Audience)은 **외부(External)** 를 고르고, 연락처 이메일을 넣고 동의한 뒤 **만들기**.
4. 왼쪽 **대상(Audience)** 으로 가서 **테스트 사용자 → + Add users** 에 **내 구글 이메일**을 추가하고 저장합니다. (이걸 안 하면 로그인이 막힙니다.)
5. 왼쪽 **데이터 액세스(Data Access)** → **범위 추가 또는 삭제** → 목록에서 `.../auth/drive` ("Google 드라이브의 모든 파일 확인, 수정, 생성 및 삭제") 를 체크하고 저장합니다.

### 3-3. 로그인용 키 만들기
1. 왼쪽 **클라이언트(Clients)** (또는 **사용자 인증 정보 → + 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**) 로 갑니다.
2. 애플리케이션 유형: **웹 애플리케이션**. 이름은 아무거나.
3. **승인된 리디렉션 URI** 에서 **+ URI 추가** 를 누르고 아래처럼 입력합니다. (2부에서 메모한 서버 주소 + `/auth/google/callback`)
   `https://wikidocs-book-to-pdf-xxxx.onrender.com/auth/google/callback`
4. **만들기** 를 누르면 **클라이언트 ID** 와 **클라이언트 보안 비밀번호** 가 나옵니다. 둘 다 복사해 둡니다.

### 3-4. Render 에 넣기
1. Render 서비스 화면 → **Environment** → `GOOGLE_CLIENT_ID` 에 클라이언트 ID, `GOOGLE_CLIENT_SECRET` 에 보안 비밀번호를 붙여넣고 **Save Changes**. 서버가 자동으로 다시 시작됩니다(1~2분).

> 처음 로그인할 때 "Google에서 확인하지 않은 앱" 경고가 나옵니다. **고급 → (앱 이름)(안전하지 않음)으로 이동** 을 누르면 됩니다. 내가 만든 앱이고 테스트 사용자로 등록한 내 계정만 쓰기 때문에 정상입니다.
> 테스트 모드에서는 로그인이 **7일마다 만료**됩니다. 만료되면 앱에서 다시 로그인하면 됩니다.
> 폴더를 고르고 그 안에 파일을 만들려면 넓은 권한(`drive`)이 필요해서 이 권한을 씁니다. 서버는 토큰을 메모리에만 두고, 서버가 다시 시작되면 사라집니다.

## 4부. APK 받아서 폰에 설치하기

1. 브라우저에서 GitHub 저장소 `https://github.com/jeong-jihyun/wikidocs-book-to-pdf` 를 엽니다.
2. 위쪽 **Actions** 탭 → 왼쪽 **Build Android APK** → 맨 위 실행(노란 점 = 진행 중, 초록 체크 = 완료)을 확인합니다. 처음엔 10~20분 걸립니다.
   - 자동으로 시작되지 않았으면 오른쪽 **Run workflow** → 초록 **Run workflow** 버튼을 누릅니다.
   - 빨간 ✗ 가 뜨면 그 실행을 눌러 로그를 캡처해 알려 주세요.
3. 완료되면 저장소 첫 화면 오른쪽 **Releases** 에서 **최신 테스트 APK** 를 누르고, 아래 **Assets** 의 `wikidocs-pdf.apk` 를 **폰 브라우저로** 내려받습니다.
   (또는 실행 화면 아래 **Artifacts** 의 `wikidocs-pdf-apk` — 압축 파일이라 풀어야 합니다.)
4. 내려받은 파일을 누르면 "출처를 알 수 없는 앱 설치" 허용을 묻습니다. **설정 → 이 출처 허용** 을 켜고 돌아와 **설치** 를 누릅니다.
5. Play 프로텍트가 "안전하지 않은 앱 차단"을 띄우면 **자세히 → 무시하고 설치** 를 누릅니다. (테스트용 키로 서명해서 나오는 안내입니다.)

## 5부. 앱 사용하기

1. **서버 연결** 칸에 2부에서 메모한 **서버 주소**와 **API 키**를 붙여넣고 **연결 테스트** 를 누릅니다. "연결 성공" 이 나와야 합니다. (잠든 서버는 1분쯤 기다려요.)
2. **책 주소** 는 `https://wikidocs.net/book/17550` 처럼 넣습니다. 처음엔 **변환할 페이지 수 = 5** 로 시험해 보세요. (0 = 전체)
3. 드라이브에 저장하려면 **구글 계정으로 로그인** → 로그인 후 **저장할 폴더 고르기**.
4. **변환 시작** 을 누르면 진행 막대가 움직입니다. 앱을 닫아도 서버는 계속 작업하고, 다시 열면 이어서 보여 줍니다.
5. 끝나면 **PDF 받아서 열기**(폰에 저장·공유), **드라이브에 저장** 을 누릅니다.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| "서버에 연결할 수 없습니다" | 서버 주소 오타, `https://` 포함 여부. 브라우저에서 `주소/health` 가 열리는지 |
| 연결 테스트에서 "API 키가 올바르지 않습니다" | Render → Environment 의 `API_KEY` 값을 다시 복사 (앞뒤 공백 주의) |
| 로그인 버튼에서 "구글 로그인 설정이 없습니다" | 3-4 의 두 값 입력 후 서버가 다시 시작됐는지 |
| 구글 화면에 `redirect_uri_mismatch` | 3-3 의 리디렉션 URI 가 서버 주소와 **글자 하나까지** 같은지 (`https`, 끝에 `/` 없음) |
| 구글 화면에 "액세스 차단됨 / 테스트 사용자" | 3-2 의 4번, 내 이메일을 테스트 사용자에 추가 |
| 변환이 "접근이 거부되었습니다(403)" 로 멈춤 | 위키독스가 서버(Render) 접속을 막은 것. 잠시 뒤 다시 시도하거나 알려 주세요 |
| "서버가 이 작업을 기억하지 못합니다" | 무료 서버가 다시 시작된 것. 처음부터 다시 시작 |
